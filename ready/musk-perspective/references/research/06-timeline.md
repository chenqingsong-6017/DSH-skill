## 一、完整生平时间线

### 1.1 童年与南非时期（1971–1989）

| 时间 | 事件 | 对他思维方式的影响 |
|---|---|---|
| 1971-06-28 | 出生于南非比勒陀利亚（Pretoria）；母亲 Maye Musk（加拿大籍模特/营养师），父亲 Errol Musk（工程师） | 双亲背景一"硬"（工程）一"软"（营养/美学），后来他的产品观始终同时追求工程可行与体验观感 |
| 1970s–1980s | 童年大量阅读，通读《大英百科全书》、科幻与奇幻作品（《银河系漫游指南》《基地》系列）；父母于 1980 年离异，他选择与父亲同住 | 形成"以百科全书为知识底座 + 以科幻为可能性边界"的双轨认知；家庭破裂强化了对"可控系统"的偏好，也埋下后来情感表达方式偏硬、偏功能化的伏笔 |
| 约 1983（12 岁） | 自学编程，写出太空射击游戏 **Blastar**，以约 500 美元售出 | 第一次验证"一个人 + 一台电脑 = 可交付产品"；确立了他终身的方法论：**先做可运行的原型，再谈规模** |
| 1988–1989 | 在 Pretoria Boys High School 毕业后，为避免南非强制兵役、并以母亲国籍为跳板移居加拿大 | 早期就表现出"用迁移规避系统性约束"的思维——后来他把同一逻辑搬到能源（摆脱石油）、航天（摆脱一次性火箭）、芯片（摆脱代工厂） |

### 1.2 北美求学与第一次创业（1989–1999）

| 时间 | 事件 | 对他思维方式的影响 |
|---|---|---|
| 1989 | 移居加拿大，寄居亲属家，做过农活、锅炉清理等体力工作 | 强化"物理世界很贵、很脏、效率很低"的直觉，这是后来"第一性原理 + 垂直整合"的情感根源 |
| 1990–1992 | 安大略省皇后大学（Queen's University） | 过渡期 |
| 1992–1995 | 转学宾夕法尼亚大学，1995 年获物理学学士 + 沃顿商学院经济学学士 | **双学位是他思维的物理锚点**：物理学给"第一性原理/量级估算"，经济学给"成本曲线/规模效应"。他此后所有论证几乎都是这两者的合流——"这个东西的物理下限是多少？做到百万台的成本是多少？" |
| 1995 | 入读斯坦福大学材料科学/应用物理博士，**两天后退学**投身互联网 | 确立"机会窗口优先于 credential"的判断逻辑；也形成了他对学术界/同行评议的长期轻视 |
| 1995–1999 | 与弟弟 Kimbal 创办 **Zip2**（在线商户目录/城市指南）；1999 年康柏（Compaq）以 3.07 亿美元收购 | 第一次经历"创始人被董事会边缘化"——他后来对控制权（超级投票权、董事会结构）的执念直接源于此 |
| 1999 | 创办 X.com（在线银行） | "X" 作为品牌母题的起点，二十多年后成为他整套商业帝国的命名内核 |

### 1.3 PayPal 与"把全部身家押进去"（1999–2002）

| 时间 | 事件 | 对他思维方式的影响 |
|---|---|---|
| 2000 | X.com 与 Confinity（Thiel/Levchin）合并 | 与 Peter Thiel 的第一次深度交集，也是后来"PayPal Mafia"网络与反主流文化立场的起点 |
| 2000-09 | 在度蜜月途中被董事会罢免 CEO（由 Thiel 接任） | 第二次被董事会"政变"，是他此后对治理结构极度敏感的创伤点 |
| 2002-07/10 | eBay 以约 15 亿美元收购 PayPal；马斯克作为最大股东约得 1.8 亿美元 | 验证了"退出不是终点，而是下一轮筹码" |
| 2002 | 创办 SpaceX；同期开始研究火星移民与"火星绿洲"构想 | **关键转折**：他没有分散投资，而是把几乎全部现金同时压进火箭（SpaceX）与电动车（2004 年投资特斯拉）——"全部押注 + 接受归零风险"成为他此后所有决策的默认姿态 |

### 1.4 双线并行：SpaceX 与 Tesla（2002–2012）

| 时间 | 事件 | 对他思维方式的影响 |
|---|---|---|
| 2002-05 | SpaceX 成立；目标是把发射成本降一个数量级，使火星移民在经济上可行 | 首次完整实践"从物理下限倒推成本"：火箭原材料成本只占售价 2%，因此"贵"是工程与组织问题，不是物理问题 |
| 2004 | 投资特斯拉（A 轮），成为董事长 | 把"电池成本 = 原材料成本 + 制造效率"这套估算方法从航天平移到汽车 |
| 2006 | 发布《特斯拉秘密蓝图》（Master Plan Part I）：跑车→平价车→更平价车→同时提供太阳能 | 确立了"**先钉死目的地，再倒推引擎**"的路径设计习惯；二十年后 Master Plan IV 仍是同一结构 |
| 2008 | 金融危机中特斯拉与 SpaceX 双双濒临破产；Falcon 1 第四次发射成功（9 月），年底获 NASA 16 亿美元 COTS 合同 | **最大的心理转折点**。他自己说过 2008 年是他"最痛苦的一年"。此后形成"以极限压力测试组织"的管理风格，以及对"破产是真实选项"的坦然 |
| 2008-10 | 出任特斯拉 CEO 兼产品架构师 | 从投资人变成操盘者，"架构师"头衔一直保留至今 |
| 2010-06 | 特斯拉 IPO（NASDAQ: TSLA） | 个人财富引擎切换 |
| 2012 | Model S 上市；同年成为亿万富翁 | 验证了"高端切入→规模下探"的反向路径可行 |

### 1.5 平台期与规模化（2013–2020）

| 时间 | 事件 | 对他思维方式的影响 |
|---|---|---|
| 2013 | 发布 Hyperloop 白皮书（开源构想）；Model S 获市场认可 | "发布构想本身就能改变议程"——开源式影响力的开始 |
| 2014 | 公开特斯拉全部专利 | 反直觉的竞争观：他认为真正的壁垒是执行速度与制造能力，不是专利 |
| 2015 | 创办 OpenAI（联合）；成立 Neuralink；Falcon 9 首次陆上回收成功 | 三条新战线：AI 安全、脑机接口、可复用火箭——全部围绕"文明级风险对冲" |
| 2016 | 发布 Master Plan Part II（太阳能屋顶一体化、自动驾驶、车辆共享）；创办 The Boring Company | 把"交通/能源/城市"视为一个耦合系统 |
| 2018 | Model 3 量产"生产地狱"；SEC 就"资金已落实"推文起诉并和解；特斯拉董事会通过史上最大 CEO 绩效薪酬方案（后被特拉华法院撤销） | **组织观转折**：他开始公开厌恶"流程/层级/会议"，形成"删到不能再删"的管理原则；与监管的第一次重大冲突 |
| 2019 | Cybertruck 发布；星舰（Starship）原型开建 | 产品审美从"流线"转向"结构外露"，映射他对"功能优先于讨好"的信念 |
| 2020 | 成为全球顶级富豪；特斯拉市值超越传统车企总和 | 财富量级改变他与资本市场对话的方式 |

### 1.6 平台、AI 与政治（2021–2025）

| 时间 | 事件 | 对他思维方式的影响 |
|---|---|---|
| 2021 | 比特币/狗狗币公开表态；星舰 SN 系列试飞 | 开始把"公开表态"当作市场变量本身来使用 |
| 2022-04 | 启动收购 Twitter；10 月以 440 亿美元完成，改名 X | **重大转折**：从"造物"转向"争夺叙事基础设施"。他的逻辑是：如果公共讨论空间被他认为的偏见所占据，那么再好的工程也推不动 |
| 2023 | 成立 xAI；发布 Grok-1；Neuralink 获 FDA 人体试验批准 | AI 从"参与投资"变成"亲自下场"，理由是他对既有实验室的安全取向不信任 |
| 2024 | 公开支持特朗普并投入逾 2.5 亿美元助选；Falcon 9 年发射次数破纪录 | 从"技术企业家"变成"政治参与者"，这一段在他 2026 年被自己评价为"过于卷入" |
| 2025-01 至 2025-05 | 领导 DOGE（政府效率部），5 月退出 | 首次把"删流程"的企业方法搬到联邦政府；结果争议很大，直接触发后续政治反思 |
| 2025-06 | 因"大而美"预算法案与特朗普公开争执，扬言成立"美国党" | 冲突式表达的高点，也是他后来与共和党重新结盟前的低谷 |
| 2025-09 | Master Plan Part IV 发布，首次提出"可持续丰裕"（sustainable abundance） | 使命从"能源转型"升级为"丰裕"，标志他把机器人/AI 视为文明级产出引擎 |

## 五、给 Skill 构建者的提示

1. **命名已改变**：2026-02 起 xAI 成为 SpaceX 全资子公司，2026-07 起对外品牌为 **SpaceXAI**。2026-10 的语境下，说"xAI"通常指 SpaceX 的 AI 部门，而不是独立公司。
2. **使命已改变**：2026-01 起特斯拉使命是"建设一个富足非凡的世界"（amazing abundance），不再是"加速世界向可持续能源的转变"。这个改动是他把 Optimus / AI 定位为文明级产出引擎的语言证据，也是万亿美元薪酬方案的正当化框架。
3. **重心已改变**：SpaceX 于 2026-02-08 把重心从火星转向**月球自给城市**，火星推迟 5–7 年；2026 年底的火星窗口实质上已放弃，下一窗口 2028–2029。
4. **政治姿态已改变**：2025-06 决裂 → 2025-09 破冰 → 2026-01 修复 → 2026-07 公开表示"过于卷入政治"→ 2026-10 以 America PAC 大额资金支持共和党参议院选战。**从"亲自上台"转为"出钱不出面"**。
5. **最高频的近期思维动作**：垂直整合（自己造芯片 → 自己造机器人 → 自己造电站/数据中心 → 自己造火箭送上去）。Terafab 是这条链路的最新一环，也是他自称"世界上最难的事情之一"的承认。
