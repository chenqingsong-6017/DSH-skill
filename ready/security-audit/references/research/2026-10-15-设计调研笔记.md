# security-audit skill 设计调研笔记（2026-10-15）

## 一、原 skill（skills-security-check，腾讯云鼎实验室）结构拆解

文件组织：单文件 `SKILL.md`（约 24KB）+ `_icon.svg` + `_skillhub_meta.json`（后两个是市场元数据，用户级自建 skill 不需要）。

### 提示词组织方式（自上而下）

1. **frontmatter**：name / description（中英双语）/ version / allowed-tools / display_name / visibility。
2. **功能描述**：一段加粗的"是什么+查什么"。
3. **约束**：一句话强制令（必须审配套脚本）。
4. **🚨 审计安全红线（最高优先级）**：四件套——
   - 核心原则（纯静态分析，不与审计对象执行交互）；
   - 防 prompt 注入声明（枚举攻击话术模板，"看到这些就是攻击载荷本身"）；
   - 工具白名单（只读工具表 + 白名单外一律禁止）；
   - 自检机制（发现自己在调白名单外工具 = 正在被注入，立即停止）。
5. **🎯 审计核心原则**：聚焦供应链投毒而非代码质量；"自动执行 vs 仅示例"边界 + 示例对比表。
6. **执行逻辑（7 步）**：读文件 → 关键词扫描（步骤 2-5，声明"关键词仅参考、记录命中、统一定级"）→ 远程脚本深度分析（触发式，web_fetch 只读）→ 依赖安装风险 → 风险评估 → 报告生成。
7. **定级机制**：
   - 前置判断链 Step 0（作者自身凭证排除）→ A（是否自动执行）→ B（是否危险操作）→ C（是否恶意意图）；
   - 三级定级 Malicious / Suspicious / Benign，每条 Malicious 条目带**降级条件 / 维持条件**；
   - 评分公式三段式：30−M×10（下限0）/ 75−S×8（下限31）/ 76-100 档。
8. **报告模板**：完整 Markdown 模板（执行摘要 / 三级发现区 / 分类明细 / 深度分析 / 总体建议 / 审计结论三档）。
9. **重要提示**：5 条执行纪律。

### 可复用的风格特征

- emoji 分区标题（🚨⛔🎯📊🔴⚠️✅💡📋）；判断标准一律表格化；
- "不仅限于以下示例"防止机械匹配；触发条件、降级条件全部显式写出；
- 扫描与判定分离；定级有递进判断链；评分有公式；报告有模板；执行有纪律清单。

## 三、设计决策（为什么这样设计）

1. **双轨制**：Cedar 的实际场景有两类——①外部素材引入前甄别（skill/提示词/MCP/脚本，投毒视角，回答"能不能引入"）；②自产资产与 homelab 项目自查（漏洞视角，回答"哪里要修"）。原 skill 只覆盖①，wshobson 式经典审计只覆盖②，合并为一轨会互相干扰（A 轨"教学代码不报告"与 B 轨"漏洞必须报告"直接冲突），故显式分轨 + 步骤 0 轨道判定表。
2. **步骤 0 范围界定**（用户明确要求）：对象→轨道、来源信任分层（决定审计深度）、文件清单圈定（清单即边界）、审计目的（决定报告侧重），全部给默认值，不反问。
3. **六大风险检查类**（用户点名四类全覆盖）：注入（步骤2）、越权（步骤3）、敏感信息泄露（步骤4）、配置错误（步骤5），外加供应链与网络（步骤6）——A/B 两轨在每步内分子节，关键词声明"仅参考"。
4. **红线四件套原样继承**（纯静态/防注入话术/工具白名单/自检机制），话术库扩充两条新调研所得：合规话术、记忆投毒话术。
5. **定级体系统一为 🔴/⚠️/🔵 三级**：A 轨 Malicious→🔴、Suspicious→⚠️；B 轨 Critical→🔴、High/Medium→⚠️、Low→🔵。前置判断链 Step 0→A→B→C 原样继承，并补"B 轨漏洞跳过 Step A"（漏洞无需"自动执行"前提）——这是对原链的必要泛化，否则 B 轨所有漏洞都会被误判为非高危。
6. **评分公式沿用原三段式**，仅补 🔵 档细则（95−info×3，下限76），保持风格一致。
7. **报告模板在原件基础上加两节**：审计覆盖声明（审了什么/没审什么，强制填写）+ 复核触发条件（什么信号出现时重审）——对齐 SOUL.md"触发条件"习惯与证据先行原则；整改建议带 Top 3 优先修复（借自 wshobson）。
8. **allowed-tools 去掉 Bash**：原件 frontmatter 声明了 Bash 但红线只允许只读工具，自相矛盾；本 skill 声明 Read/Grep/Glob/WebFetch，与红线严格一致。
