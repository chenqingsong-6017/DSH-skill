# 出厂评分卡与双审计工序（Phase 4）

> 目录：否决项 → 引语/事实审计工序 → 双盲保真评分（5 维 100 分）→ FIDELITY.md 模板 → 反作弊 → 棘轮迭代
>
> 回答一个问题：**这个 skill 跑起来到底像不像、诚不诚实？**
> 铁律：LLM 自评 skill 质量准确率仅 46.4%（SkillLens，arXiv 2605.23899）——答题 agent 与评分 agent 必须独立，生成者不得兼任任何一方。

## 一、否决项（任一命中即 D 级回炉，不看总分）

| # | 否决项 | 为什么 |
|---|---|---|
| V1 | 引语/事实审计未跑 | 本流程最大硬伤来源（事实倒置、年代错置），跳过等于没质检 |
| V2 | 审计发现 ≥1 处事实倒置或张冠李戴 | 一处倒置说明调研链路失守，不止一处 |
| V3 | 在世人物使用无「冻结快照」标注的新闻块 | 时效氧化必然误导（已实测） |
| V4 | 骨架 B 缺出口自检/角色边界/熔断条款 | 下判断型人物无边界＝现代议题失控（已踩过） |
| V5 | 附录 B 黑名单中的伪语录出现在正文 | 伪知识进正文＝蒸馏失败 |
| V6 | 直觉条目无原句锚点（或锚点＝「网络流传」） | 无锚点的直觉＝编造，比漏写更糟——它看起来最像「人性洞察」 |
| V7 | 低有效性领域的直觉被写成可复用判断依据且无标注 | K&K：低有效性环境里反馈慢或无序，笃定是自信不是专长 |
| V8 | 事后合理化／情绪／领域外自信冒充直觉进正文 | 伪直觉污染判断链路，且下游读者无法识破 |

## 二、引语/事实审计工序（第一道，先跑）

1. 另起一个**独立子 agent**（干净上下文，未参与生成）。
2. 任务：把 skill 内**每个引号句、每个年代、每个人名-事件归属**逐条列为审计项。
3. 每条核对：出处是否真实存在 → 原话是否如此（非大意改写冒充原话）→ 年代是否错置 → 归属是否倒置。
4. 产出：`audit-quotes.md`，逐条给 [✓ 一手核实 / ⚠️ 二手转引已标注 / ✗ 错（附正确版本）]。
5. ✗ 条清零才进第二道；⚠️ 条保留但须在各条处带「据…」标注。
6. **直觉条目的锚点句走同一道审计**——它们也是引语，不另开流程。额外加一步：标【追认】的锚点，核对是否与**当时**的记录矛盾（事后合理化筛查：多年后的复盘把当时没想过的东西说成「我当时就想」）。

## 三、双盲保真评分（第二道）

与女娲官方同尺（5 维 100 分），便于与官方产物互测对比。

| # | 维度 | 分值 | 测什么 | 怎么测 |
|---|------|------|--------|--------|
| 1 | 立场一致性 | 30 | 对其公开表态过的问题，回答方向是否一致 | 3 道已知立场题，每题 10：方向细节全对=10 / 方向对细节偏=6 / 立场偏离=0 |
| 2 | 风格辨识度 | 20 | 不看名字能否从表达认出是谁 | 评分 agent 盲读：句式/用词/类比是否有此人指纹，还是通用 AI 腔；过度模仿成 caricature 同样扣分 |
| 3 | 边缘诚实度 | 20 | 超范围题：标推断还是斩钉截铁编造 | 1 道此人未谈过的题：声明「框架推断」并保留不确定=满分；伪装本人观点断言=0 |
| 4 | 来源透明度 | 15 | 调研底稿可溯源 | 静态检查：research/ 目录存在、一手占比>50%、附录 A 引语逐条带出处、附录 B 黑名单存在 |
| 5 | 结构完整度 | 15 | 防漂移与诚实运行的完整结构 | 静态检查：心智模型 3-7 个且**每个带形成故事**、诚实边界≥3 条含调研日期、内在张力≥2 对、三件套齐全、**回答工作流存在且研究维度与心智模型对应、首步为「线索扫描」**、**直觉层 3-6 条且每条含触发线索＋来源锚点＋有效性等级（或带原因的留空声明——留空不减分，硬凑假条目按 V6 处理）**、启发式为第一人称习惯式（非 Step 1/2/3 推理步骤）、表达DNA ≤3+3、（骨架B）出口自检+熔断、（在世）冻结快照标注 |

等级：A ≥85 出厂精品 / B 70-84 合格有标注薄弱点 / C 55-69 慎用 / D <55 回炉重蒸。

### 执行流程

1. **出题**：3 道已知立场题（选其公开反复表态的话题）+ 1 道超范围题 + 1 道风格样本题；避开 skill 内已有示例对话（防背答案）。
2. **答题 agent**：只读该 skill 目录内文件，按 skill 激活人物作答，**禁联网**，且不知道自己被测哪个维度。
3. **评分 agent**：独立 agent，拿答题结果 + 本 rubric + skill 路径，对照人物真实公开立场逐维打分。
4. 重要结论用 2 个评分 agent 独立跑，分差 >10 人工复核。
5. 产出：`FIDELITY.md` 存 skill 目录。

## 五、棘轮迭代（Phase 5 接口，达尔文 v2.1 口径）

1. 算 weighted_gap = weight × (10 − score) / 10，找最大短板维度（避免低权重维度制造进步幻觉）。**绝对分数只用于这一步 triage（决定先改谁），不做 keep/revert 依据**——实测同一评委对同一份未改文字换次评分可摆 ±8，分数 delta 会淹没保守编辑的真实增益、造成 false-revert。
2. **一轮只改一个维度**；优化针对评分暴露的**失败模式**，把失败路径显式编码回 skill，不写「下次注意」。
3. **keep/revert 用 paired 同-judge 比较**：同一评委拿改前/改后两版，对照 rubric 当比较准则（不是各打绝对分），回 {better | worse | tie} + margin{clear | slight} + 一句理由；**奇数 ≥3 评委多数决**——tie 或 slight 多数即 keep，worse 多数才 revert。
4. **validation-gated**：改进必须重过 Phase 4 测试题（至少立场一致性 3 题）才 keep；revert 用 git revert 建反向提交，不用 reset --hard。
5. **迭代上限**：提炼→审计最多循环 2 轮，或 margin 连续两轮 ≤slight 即停——交付当前最优，剩余薄弱项写进诚实边界，不无限打磨。
