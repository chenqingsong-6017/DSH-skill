# 反模式库：翻车档案 → 可检测特征 → 闸门位置

> 素材全部来自 2026-10-09~10-15 六次人物蒸馏实战（李白/毛泽东/乔布斯/杜甫/费曼/马斯克）的真实翻车记录。
> 用法：Phase 0 读一遍避坑；Phase 4 审计时当检查清单；新翻的车随时补录。

| # | 翻车现场 | 可检测特征 | 编入的闸门 |
|---|---|---|---|
| 1 | 事实倒置：事件因果/归属写反（杜甫 v1 4 处硬伤） | 引语审计中「人物-事件-年代」三元组对不上 | Phase 4 否决项 V2 |
| 2 | 年代错置：把后期观点安在早期、把身后事写进「我现在」 | 时间线年份与正文引用年份冲突 | Phase 4 引语审计 |
| 3 | 引诗错配：A 诗的诗句挂到 B 诗题下 | 引号句与出处标题不符 | Phase 4 引语审计 |
| 4 | 身份卡写入后世尊号（「世人尊我诗圣」），与诚实边界「身后所加生前不自知」直接打架 | 身份卡出现「世人/后人/史称/被誉为」+ 诚实边界有相反表述 | person-template 身份卡对冲检查清单 |
| 5 | 骨架误用：给「下判断型」人物（杜甫）套「不下判断型」（李白）的松散结构 → 现代议题失控（滑向当代时政评论/编造数据/只抒情不给方案） | 人物言论中价值判断密度高，但 skill 无出口自检与角色边界 | Phase 0 骨架 A/B 分流；否决项 V4 |
| 6 | 在世人物冻结新闻氧化：skill 内「最新动态」比联网事实旧 → 反而不如无 skill 的 agent 准 | 「最新动态」块无截止日期、无「需搜复核」声明 | Phase 3 时效框架；否决项 V3 |
| 7 | 无一手出处的流行术语被当本人思想（idiot index 等 8 条） | 引语只有二手转引、找不到原始视频/文字 | research-protocol 伪语录排查 → 附录 B 黑名单；否决项 V5 |
| 8 | 个人决策建议零反问：用户问「我该怎么办」直接给方案，不问目标/约束/时限 | 起手式无「补参数」步骤 | person-template 起手式第 2 条 + 闸门第 1 条 |
| 9 | 危险启发式无熔断：「全押/不切分/定死线」类建议直接输出，涉用户不可撤回利益 | 启发式清单含高风险动作，但无熔断路由 | person-template 失败预防路由「不可撤回利益先熔断」 |
| 10 | 语录合集化：正文全是原话拼贴，对新问题无预测力 | 三重验证卡「生成力」关不过仍收录 | Phase 2 三重验证；顶部仓颉验收标准 |
| 11 | 美颜滤镜：只读粉丝语料，蒸馏出神像不是人 | research/ 缺 04-批评者.md 或该文件异常薄 | Phase 1 批评者视角不可省；评分卡维度 4 |
| 12 | 子 agent 摘要超重：六路全文直接倒进主上下文 → 主上下文爆炸读不全 | 子 agent 回传 >800 字且无落盘文件 | research-protocol 子 agent 纪律第 2 条 |
| 13 | 中文长度自欺：`wc -w` 报 539「词」实际 6635 token 超规范 | 用空白分词统计中文 | Phase 3 长度纪律（按字计） |
| 14 | 模糊词开口子：「建议/根据情况/灵活把握」→ agent 现场讨价还价 | 正文出现模糊词清单词汇 | Phase 3 模糊词禁令 |
| 15 | 过度模仿成 caricature：口癖密度过高，像滑稽戏不像人 | 评分 agent 盲读报「用力过猛」 | 评分卡维度 2 双向扣分 |
| 16 | 调研全倒二手：通篇「据传记」「据文章」无一手 → 立场一致性测不过 | 一手占比 ≤50% | research-protocol 语料底线；评分卡维度 4 |
| 17 | 绝对分数 delta 做 keep/revert：同一份未改文字换个评委能摆 ±8 → 保守编辑的真实增益被误判退步回滚（达尔文 v2.1 实证） | 棘轮用「分数降了就回滚」逻辑 | fidelity-scorecard 第五节 paired 比较＋奇数多数决 |
| 18 | 启发式写成推理步骤：「Step 1: 使用逆向思维」→ agent 机械执行，遇到变式就僵死（仓颉） | 启发式出现 Step 编号/「首先…其次…」流程腔 | person-template 写法四纪律第 1 条 |
| 19 | 表达DNA 写太细：七轴量化全表进正文 → agent 用力过猛变 caricature（仓颉教训，与评分卡维度 2 双向扣分一致） | 正文出现句长统计/频率表 | research-protocol 第九节「调研期量化、写入期 3+3」 |
| 20 | 信念无形成故事：「独立思考很重要」式通用道理进模型 → 这些模型训练语料里本来就有，skill 零增量（仓颉总原则） | 模型条目找不到「因为经历了…」来历 | Phase 2 仓颉三铁律；评分卡维度 5 |
| 21 | 小窗口单会话硬跑全流程：完整蒸馏可累积 500k+ token，Phase 1-2 之间上下文爆炸（女娲真实 issue） | 200k 级窗口模型试图单会话跑完 | research-protocol 第十节分 Phase 断点续跑 |
| 22 | 不报成本直接开跑：多 agent+多轮搜索的重任务，用户面对账单才知道量级（女娲真实 issue） | Phase 0 无档位确认直接启动六路 | Phase 0A 成本透明＋默认档直接推进 |
| 23 | 检查点变成交付阻塞：把「等用户确认」当扣住产出的理由 | 检查点无「不答即继续」条款 | Phase 1.5/2.5「纠偏不是阻塞」 |
| 24 | 伪直觉·事后合理化：「我当时就觉得不对」——多年后复盘，把当时没想到的说成当时看见了 | 锚点是【追认】且无法与当时记录交叉；时态是「后来才明白」却写成「当时就看出」 | research-protocol 12.4 锚点制；否决项 V8 |
| 25 | 伪直觉·情绪化：把好恶写成判断（「他凭直觉不喜欢这个人」） | 条目写不出可观察线索，只有态度词 | 写法四纪律第 4 条；否决项 V6 |
| 26 | 伪直觉·领域外笃定：此人在低有效性领域（选股/长期预测/政治走向）的自信被写成「洞察」 | 有效性栏为「低」却标「可用直觉」；理由是「他说得很肯定」 | 有效性闸（Kahneman-Klein 2009）；否决项 V7 |
| 27 | 直觉层成摆设：写进正文但不接回答工作流 → agent 依旧上来就套模型，只是语气更像 | 回答工作流 Step 2 无「线索扫描」；正文有直觉层但无调用路径 | person-template Step 2；评分卡维度 5 |
| 28 | 把分析硬编成直觉：他明说「我算了数据」，被写成「他凭直觉一瞥」 | 原句含「算／数据／模型／我查过」但条目归入直觉 | research-protocol 12.3 反向标记 |

## 借口对照表（蒸馏过程中 agent 用过的借口，逐字收录，一律不算数）

| 借口 | 现实 |
|---|---|
| 「这句话他肯定说过类似的」 | 查无一手出处 → 附录 B，禁入正文 |
| 「这个人物大家都很熟，不用六路调研了」 | 越熟的人物粉丝滤镜越厚，批评者视角越不能省 |
| 「子 agent 报 429 失败了，重跑吧」 | 先 Read 落盘文件——它可能写完才报错 |
| 「自评一下就行，跑双 agent 太贵」 | 自评准确率 46.4%，接近随机——省掉的不是钱，是质检 |
| 「时效新闻写新一点，用户近期不会较真」 | 氧化是确定的，误导只是迟到 |
| 「wc -w 没超，长度合规」 | 中文无空格，按字计，自欺 |
| 「矛盾处我帮他圆一下更顺」 | 矛盾是人格特征，圆了就是美颜 |
| 「这个观点很有名，肯定是他的核心思想」 | 有名的观点模型早会了——没有形成故事的观点不进 skill |
| 「评委说分数降了，回滚吧」 | 绝对分 ±8 是评委换尺噪音；keep/revert 只看同评委 paired 比较的多数决 |
| 「DNA 写细一点才像」 | 写太细只会得到 caricature；3 偏好+3 禁忌，量化表留在 research |
| 「用户没选档位，先跑起来再说」 | 完整蒸馏是重 token 任务——先报量级，默认标准档直接推进，两件事都做 |
| 「直觉本来就说不上来，写模糊点才像」 | 说不上来的是那份感觉，看得见的是线索——写不出触发线索就是没采到，不是「高级」 |
| 「他只是自信，哪来的直觉」 | 先查有效性两问：环境线索稳定吗、反馈快而明确吗。都成立就是真直觉，别把专长当运气 |

## 红旗清单（出现任意一条 → 停下，回对应 Phase 重来）

- 正文出现「建议/可以考虑/根据情况/灵活把握/视情况而定」
- 身份卡出现「世人尊我/史称/被誉为」且诚实边界写着「生前不自知」
- 「最新动态」块找不到「截至」与「需搜复核」字样
- research/ 目录没有 04-批评者.md
- 引号句没有出处，或出处是「网络流传」
- 骨架 B 人物（言论里全是指认与判断）的模板里找不到「出口自检」
- 评分是生成者自己打的
- 心智模型条目里找不到「形成故事」（他为什么开始信这个）
- 启发式出现「Step 1/首先/其次」式流程腔
- 表达DNA 正文超过 3 偏好+3 禁忌
- 棘轮回滚的依据是「绝对分降了」而非同评委 paired 多数决
- Phase 0 没报成本量级就启动了六路采集
- 直觉条目只有「他感觉／他认为」，找不到触发线索
- 直觉条目有效性栏空白，或全部标「高」
- 直觉条目有效性标「低」却仍写成可复用判断依据
- 回答工作流没有「线索扫描」这一步（直觉层成摆设）
