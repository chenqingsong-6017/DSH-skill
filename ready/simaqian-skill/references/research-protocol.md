# 六路采集工序（Phase 1/2 细节）

> 目录：总原则 → 六路定义 → 仓颉 7 级扫描清单 → 本地语料模式 → 子 agent 纪律与 prompt 模板 → 语料底线 → 三重验证操作法 → 矛盾三类 → 信息不足处理 → 表达DNA 量化 → 失败降级路径 → 落盘规范 → 直觉信号采集（CDM 逆向探询）

## 〇、总原则（仓颉）

**只提取模型不可能自己知道的东西。** 此人公开发表过的观点，模型训练语料里大概率已有——skill 的真正增量是：信念的**形成故事**、决策时**在想什么**、本人承认的**失败与反思**。读素材时带着这个目标读，不是抄观点。

品味守则：**长文 > 金句**；**争议 > 共识**；**变化 > 固定**（改变立场的地方比一直坚持的更有信息量）。

## 一、六路定义与每路要回答的问题

| 路 | 采什么 | 要回答的问题 | 最低要求（标准档） |
|---|---|---|---|
| 1 著作 | 书、长文、公开信、论文、newsletter | 他反复论证的底层命题（≥3 次复现＝真信念）、自创术语、推荐书单（智识谱系） | ≥2 篇长文或 1 本书核心 |
| 2 访谈/播客/演讲 | 长对话（≥1 小时）优先，短视频切片最次 | 被追问时怎么即兴推理、改变立场的瞬间、拒绝回答的问题 | ≥1 段深度对话 |
| 3 社媒即时发言 | 推文/即刻/微博/雪球 | 未经修饰时关心什么、怎么骂人、高频词句 | ≥20 条发言 |
| 4 批评者视角 | 对手批评、差评书、争议报道 | 最聪明的人怎么反对他？哪些批评他承认过？ | ≥2 个不同立场的批评 |
| 5 决策记录 | 实际做的事：产品、投资、人事、放弃的项目 | 说的和做的在哪分叉？（做的权重 > 说的） | ≥2 个决策＋事后反思 |
| 6 人生时间线 | 编年：出身、转折、失败、复活、**最近 12 个月动态** | 哪段经历铸成了哪个模型？ | 关键转折覆盖完整 |

**批评者视角不可省**：只读粉丝语料必出美颜滤镜，蒸馏出来的是神像不是人。

## 二、仓颉 7 级扫描清单（读素材时找什么）

无论子 agent 还是主 agent 读素材，按此优先级扫描：

| 级别 | 找什么 | 命中后 |
|:---:|---|---|
| 1 最高 | **信念形成故事**（「我信 X 是因为经历了 Y」） | 逐字记录＋出处 |
| 2 高 | **真实决策复盘**（做了什么＋当时在想什么＋事后反思） | 逐字记录 |
| 3 高 | **失败/错误承认**（必须本人承认，非外部推断） | 逐字记录 |
| 4 高 | **内在矛盾暴露**（前后不一致、说一套做一套） | 标注两个矛盾点各自出处 |
| 5 中 | 认知边界声明（「这不是我的领域」） | 简要记录 |
| 6 中 | 思维习惯案例（反复出现的分析模式） | 记录具体案例 |
| 7 低 | 通用观点/金句 | **没有形成故事就跳过** |

**交叉验证**：同一信念在 ≥2 份独立素材中出现 → 标 ★ 置信度高；只出现 1 次 → 保留但标注来源单一；素材间矛盾 → 保留双方（矛盾本身是证据）。

## 三、本地语料模式（Phase 0 判定）

| 模式 | 触发 | 策略 |
|---|---|---|
| 纯网搜（默认） | 用户无素材 | 六路全走网络 |
| 本地优先 | 用户提供了文件 | 先按六维度分类消化本地素材 → 识别缺口 → 网搜只补缺失维度；来源标注「用户素材/网搜」 |
| 纯本地 | 用户明说「只用我给的」或蒸馏非公众人物 | 不网搜，只分析本地素材 |

本地素材处理：书籍 PDF→著作+表达；访谈 transcript/字幕→对话+表达；社媒导出→表达；内部文档/备忘录→决策。**本地一手素材权重最高**（未经二手过滤）。

## 四、子 agent 纪律与 prompt 模板

1. 六路**并行**派发，每路一个干净上下文的子 agent；环境不支持并行 → 串行，做一路落盘一路，禁止挂起死等。
2. 每路**全文落盘**产物 skill 的 `references/research/0N-<路名>.md`，回传摘要 **≤800 字**——摘要进主上下文，全文留磁盘。
3. 收到 failed 通知先 Read 目标文件——子 agent 可能「写完文件才报 429」，不要盲目重启。
4. 信息源黑名单（知乎/微信公众号/百度百科）永远排除；中文权威媒体与白名单渠道优先。

**spawn 任务卡模板**（以第 1 路为例，其余换搜索方向与文件名）：

```
你的任务：调研[人名]的著作和系统性长文。
搜索方向：出版书籍（书名/核心论点/年份）、长篇 newsletter/博客/论文、
反复出现 ≥3 次的核心论点（真信念）、自创术语、推荐书单（揭示智识谱系）。
输出要求：
- 写入 [skill目录]/references/research/01-writings.md
- 每条信息标注来源 URL 与可信度（一手>二手>推测）
- 区分「他说过的」vs「别人说他的」vs「你推断的」
- 按仓颉 7 级清单提取：形成故事/决策复盘/失败承认/内在矛盾优先，通用金句跳过
- 发现矛盾直接记录双方，不要调和
信息源黑名单：不使用知乎、微信公众号、百度百科。
完成后回传 ≤800 字摘要（关键发现+来源数+矛盾点）。
```

## 五、语料底线（Phase 0 用）

| 档位 | 一手语料底线 | 适用 | 产出标注 |
|---|---|---|---|
| 快速 | 3 维度×5 来源 | 先试水/冷门人物/预算敏感 | 「快速蒸馏」写进诚实边界 |
| 标准（默认） | 6 维度，≥10 万字一手（著作 1 本或等价） | 大多数人物 | 正常出厂 |
| 深度 | 6 维度＋一手素材全量存档（≥30 万字＋决策记录交叉） | 长期思维顾问/开源发布 | 可加实战对话录 |

一手占比必须 >50%；只有二手来源的人物（部分古代人物）→ 以权威原典为一手（《论语》之于孔子），研究专著为二手，诚实边界写明。可用来源 <10 条（冷门人物）→ Phase 0.5 告知质量受限，模型减至 2-3 个。

## 六、三重验证操作法（Phase 2）

对每个候选心智模型建一行验证卡：

```
候选模型：[名称]
跨域复现：领域A=[证据+出处] / 领域B=[证据+出处]  → 过/不过
生成力：用它推断[一个他没谈过的新问题] → 立场=[...]，合理吗 → 过/不过
排他性：聪明反对者会怎么想 → 若反对者结论相同则不过
形成故事：来历=[什么经历让他开始信这个]  → 无故事不进（仓颉铁律）
判定：3 过+有故事=心智模型 / 1-2 过=启发式 / 0 过=弃用
```

数量纪律：心智模型 3-7 个（太少=太浅，太多=没提炼），启发式 5-10 条，宁少勿多——3 个深刻的模型远好于 10 个浅薄的原则。每条启发式带「应用场景＋已知案例」，能被新情况触发。

## 七、矛盾三类处理

| 类型 | 识别 | 处理 |
|---|---|---|
| 时间性矛盾 | 早期说 A 后来说 B | 记录演化轨迹标「早期/近期」，Skill 以近期为主但提及演化 |
| 领域性矛盾 | 工作中 X、生活中 Y | 分领域记录，不强求统一——这是深度来源 |
| 本质性张力 | 价值观内在冲突（既自由又纪律） | 显式记为「核心张力」，≥2 对 |

禁止：选一边忽略另一边 / 编一个调和解释 / 假装矛盾不存在。

## 八、信息不足处理表

| 情况 | 处理 |
|---|---|
| 某维度公开信息很少 | 标「信息不足，此维度为推测」 |
| 只有二手信息 | 降置信度，写「据[来源]报道」 |
| 信息相互矛盾无法判断 | 并列呈现，不替他做主 |
| 此人刻意不公开某方面 | 忠实呈现那个沉默，注明「此人对此话题保持沉默」 |
| 数字口径冲突 | 两个数都写进诚实边界，不替用户选 |

**关键规则**：宁可生成一个诚实标注了局限的 60 分 Skill，也不要生成看似完美实则在编造的 90 分 Skill。

## 九、表达DNA：调研期量化，写入期收敛

**调研期**（本目录留档）：从长文/演讲随机抽 20 段统计——平均句长、疑问句比例、类比密度、第一人称频率、确定性语气比（「一定/显然」vs「也许/可能」）、转折频率；风格七轴打标（正式↔口语、抽象↔具体、谨慎↔断言、学术↔通俗、长句↔短句、铺垫↔结论先行、数据↔叙事）。

**写入期**（进 SKILL.md 的只留）：**3 条偏好 + 3 条禁忌**＋禁忌词清单（此人从不用的词）＋ 1-2 句指纹级示例。量化全表放 research 目录不进正文——详细句式分析会让 agent 用力过猛变 caricature（仓颉教训，与评分卡维度 2 双向扣分一致）。

**伪语录排查**：流行的「名人名言」若无一手出处（原始视频/原始文字记录），一律进模板附录 B 黑名单，不进正文。

## 十、失败降级路径（if-then 速查）

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 环境不支持并行子 agent | 六路串行，做一路落盘一路 | 单 agent 分 6 轮，每轮一路立即落盘 |
| 上下文窗口不足（完整蒸馏可累积 500k+ token） | 分 Phase 续跑：每 Phase 结束状态已落盘，新会话从文件恢复（调研文件本身就是断点） | 分 3 段会话：Phase 0-1 / 1.5-2.5 / 3-5 |
| 成本失控（token 消耗超预期） | Phase 0 的档位确认就是防线 | 用户中途喊停 → 已落盘调研文件即为可交付中间产物，下次续跑不清零 |
| 单路子 agent 超时/无结果 | 不等待，继续推进，Phase 2 标注「信息不足」 | 诚实边界中说明该维度薄弱 |
| 搜索工具不可用 | 改用环境可用的等价工具 | 切换纯本地语料模式，引导用户提供素材 |
| Agent 结果冲突 | 保留矛盾——矛盾本身是有价值的信号 | 用「内在张力」section 收录 |

## 十一、调研落盘规范

```
<person>-perspective/
├── SKILL.md                    # 最终产物
└── references/
    ├── research/               # 六路调研（必存）
    │   ├── 01-writings.md      # 全文提取 + 来源清单（一手/二手+可信度）
    │   ├── 02-conversations.md
    │   ├── 03-expression.md
    │   ├── 04-critics.md
    │   ├── 05-decisions.md
    │   ├── 06-timeline.md
    │   ├── 07-verify-cards.md  # 三重验证逐卡判定（第六节格式）
    │   └── 08-intuition.md     # 直觉信号（第十二节格式）
    └── sources/                # 用户提供的一手素材（books/transcripts/articles）
```

- **自包含**：所有调研存产物目录内部，复制整个目录即可独立使用——不存任何外部目录。
- **不放原文整书**：sources/ 存用户提供的素材；research/ 只保留**被引用的关键段落**与提取记录，不复制全书/全访谈原文（体积与版权双约束）。
- 调研全透明是评分卡「来源透明度」维度的静态检查依据：没有 research/ 目录，该维度直接零分。

## 十二、直觉信号采集（CDM 逆向探询）

> **目的**：把「他怎么一眼看出来」从叙述里拆出来。
> **理论底盘**：Klein 识别启动决策（RPD）——专家按模式识别情境，产出四个副产品：**线索 cues / 预期 expectancies / 目标 goals / 行动脚本 action-script**，再心理模拟验收；实测 80–90% 的决策**不比较选项**。CDM（Klein, Calderwood & MacGregor, 1989）是把这套隐性知识问出来的标准访谈法，本节是它的**文本版**——LLM 访谈不到本人，只能对已发表的叙事做逆向探询。

### 12.1 Pass 1：先找对段落（选事件）

只对**叙事性复述**做探询，不对观点句做。合格段落有四个特征，**命中 ≥2 才值得挖**（否则纯浪费 token）：

- **非例行**：出了意外／有争议／事后被反复讲
- **多决策点**：叙述里有「我本来想…后来改成…」
- **有认知转折**：「一开始我以为…直到我看到…」
- **有他人对照**：「别人都说…但我看…」

### 12.2 Pass 2-4：四轮探询问句（读素材时自问，不是问用户）

| 轮 | 问句 | 产出 |
|---|---|---|
| **时间线** | 判断在哪一刻转向？转向前后他各知道什么？ | 认知状态变化序列 |
| **线索** | 他点名的**具体信号**是什么（数字／表情／气味／一处不协调）？哪些他没提但显然在用？ | 线索表（最值钱） |
| **目标／选项** | 那一瞬间他在保什么？有没有提别的可行动作？ | 目标＋选项集 → 判定「秒判 vs 权衡」 |
| **假设** | 如果那条关键信息没到手，他会怎么做？如果那个信号是假的呢？ | 模型边界（钉住形状的钉子） |
| **新手错** | 他说「外行会以为…」的地方是什么？新手看不见哪条线索？ | 排他性线索（最能体现专家性） |

### 12.3 直觉标记语检索表（定位段落用）

**中文**：我一看／我一眼／直觉／感觉不对／不对劲／这不像／我闻出味／这里有问题／不用看数据／说不上来但／我第一反应
**英文**：gut feeling / I could tell / something felt off / I just knew / smelled wrong / didn't need the data / my first instinct

**反向标记（同等重要）**：他明确说「我是算出来的／我有数据／这有模型」→ 这是分析不是直觉，**别硬编成直觉**。把分析写成直觉，是比漏采更严重的失真。

### 12.4 三级来源锚点（每条必须挂一个）

| 等级 | 什么样 | 可信度 |
|---|---|---|
| 【自述】 | 本人讲「我当时看到 X 就知道 Y」 | 最高，仍可能事后美化 |
| 【旁证】 | 他人观察「他没翻数据就否了」 | 高，但有归因误差 |
| 【追认】 | 本人多年后复盘那次判断 | **最低**——事后合理化高发区，须与当时记录交叉验证 |

无锚点 → 只进「推测区」，标「框架推测，非本人自述」。

### 12.5 有效性判定（Kahneman & Klein 2009）

对每条直觉填两问：

1. **环境有效性**：该领域的线索与结果之间有无稳定关系？（高：急救／消防／工程调试／手术；低：长期预测／选股／政治走向／单次招聘）
2. **学习条件**：他是否在该领域有大量重复练习，且拿到**快而明确**的反馈？

- 两问都「是」→ 标「可用直觉」
- 任一为「否」→ 标「自信／立场，非可复用直觉」，**写明缺哪条**
- **禁止**用「他说得很肯定」「他成就很高」当有效性证据——K&K 明文：没有主观标记能区分真直觉与启发式偏见。

### 12.6 落盘格式（写入 `08-intuition.md`，每条一节）

```
[直觉条目名]
触发线索：…
预期：…
当时的目标：…
行动脚本／秒判还是权衡：…
事后归因（他怎么把直觉翻译成理由）：…
失效案例（本人承认的错判）：…
锚点：【自述/旁证/追认】原句＋出处
有效性：高/中/低 ＋ 两问答案
可用性：可用直觉 / 自信·立场（缺哪条）
```

### 12.7 置信度分级与降级

| 素材类型 | 可做几轮 | 标注 |
|---|---|---|
| 长对话／访谈 transcript | 完整四轮 | 正常 |
| 传记／史传（古代人物） | 只能做线索＋新手错两轮 | 「文本重构，非本人自述」，置信度降一级 |
| 只有二手转述 | 不做，只进推测区 | 「据他人转述」 |

**数量纪律**：直觉条目 3-6 条，宁少勿多——每条都要能回答「下次遇到什么情形会触发它」。凑数的直觉条目在 Phase 4 会连累结构完整度。
