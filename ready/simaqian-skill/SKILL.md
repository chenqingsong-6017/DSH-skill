# 太史公 · 人物蒸馏术

> 铁律一：**没有六路调研，不写心智模型。** 凭模型记忆蒸馏＝语录合集，不是认知框架。
> 铁律二：**没有独立审计，不准出厂。** LLM 自评 skill 质量准确率仅 46.4%（SkillLens，arXiv 2605.23899）——答题与评分必须是两个独立 agent，绝不自评自证。
> 铁律三：**直觉不靠推断，靠锚点。** 「他大概会凭直觉觉得…」是编造，不是蒸馏。可捕捉的只有直觉的**输入（线索）与出口（秒判／事后归因）**，那份感觉本身捉不到——见「直觉层」。
> 总原则（仓颉）：**只提取模型不可能自己知道的东西。** 公开观点模型早会了，skill 的增量在「他为什么这样想」——形成故事、决策时的推理、本人承认的失败。

为真实人物立传：**究天人之际（六路调研）→ 通古今之变（时间线与观点演化）→ 成一家之言（可运行的 Skill）**。

验收标准只有一条：**删掉名字后，还能从对新问题的回答里认出这是谁的思维方式。** 不是说得像，是想得像；不是复读语录，是框架运行。

## 何时使用 / 何时不用

| 用户输入 | 路由 |
|---|---|
| 「蒸馏 XX」「做个 XX 视角/思维/认知 skill」 | → Phase 0A（直接路径） |
| 「我想提升决策质量」「有没有一种思维方式能帮我…」（模糊需求） | → Phase 0B（诊断路径） |
| 「更新 XX 的 skill」「XX 最近有新动态」 | → 更新模式（只增量，不重写） |
| 「优化这个人物 skill」 | → Phase 4 起（审计与棘轮） |
| 蒸馏一个领域主题（如「价值投资」「反脆弱」）而非具体的人 | → 说明：本 skill 只造人物；主题蒸馏当普通任务处理或转 skill-dev Phase 0 |
| 开发/审计工具型 skill | → skill-dev |
| 用已有人物 skill 答问题 | → 直接激活那个 *-perspective skill |

## 六阶段工序

### Phase 0 · 立项与风险结构评估

**0A 直接路径**（用户给了明确人名）：确认四件事——

1. **此人下判断吗？**（可观察谓词：其公开言论中价值判断与因果指认的密度）——决定骨架 A/B，见下节。
2. **语料档位**：快速（3 维度×5 来源，先试水）/ 标准（默认，6 维度，≥10 万字一手）/ 深度（6 维度＋一手素材全量存档，准备开源发布的精品）。**开跑前报成本量级**：完整蒸馏是多 agent＋多轮搜索的长任务，token 消耗大，用户有权先选档再花钱。用户说「就做 XX」无更多信息 → 默认标准档直接推进——**确认不阻塞交付**：能给默认值就给默认值，先出产出再让用户调。
3. **本地语料吗？** 主动问一句：「你手上有没有此人的一手素材（书 PDF/访谈 transcript/字幕/博客导出）？有的话丢给我，比网搜质量高得多。」有 → 标记本地语料模式（采集策略见 research-protocol.md）。
4. **在世还是已故？** 在世→Phase 3 启用「时效框架」槽位；已故→事实路由走「档案员口吻」。

**0B 诊断路径**（用户只有困惑没有人选）：最多 2 轮追问定位需求场景（决策/表达/创业/教学/批判/人生策略哪一类），然后推荐 ≤3 个候选人物，每个写清「核心镜片 / 为什么适合你 / 这个视角的盲区」——候选要有差异性，必须说局限，没有万能框架。用户选定 → 回 0A。

**0.5 建目录**：调研前先建 `<person>-perspective/` 目录（含调研子目录与用户素材子目录，结构规范见 research-protocol.md 第十一节）。**自包含原则**：所有调研文件必须存在产物 skill 目录内部——复制整个目录就能独立使用，不依赖任何外部文件。

产出：一行立项句——「蒸馏 [人名]，骨架 [A/B]，档位 [快速/标准/深度]，语料 [网搜/本地/混合]，风险点 [1-2 条]」。

### Phase 1 · 六路并行采集

STOP. 读 `references/research-protocol.md` 后再继续。

六路子 agent 并行：**著作 / 访谈播客 / 社媒即时发言 / 批评者视角 / 决策记录（做了什么，不只说了什么）/ 人生时间线（含最近 12 个月动态）**。核心纪律：

- 每路**全文落盘**产物 skill 的调研目录，回传摘要 ≤800 字。
- **批评者视角不可省**——只读粉丝语料必出美颜滤镜。
- 一手来源占比 >50%；本地语料模式时用户素材权重最高，网搜只补缺口。
- **直觉信号同步打捞**：六路跑完不是收工——按「直觉层」的四轮探询做一遍逆向扫描（线索／预期／目标／行动脚本＋秒判／事后归因／失效案例），单列 `08-intuition.md`。这是唯一能拿到「他怎么一眼看出来」的通道，补采比返工便宜。
- 品味守则：**长文 > 金句**（3000 字 essay 比 50 条推文更揭示思维结构）；**争议 > 共识**（最被争议的观点最能揭示独特性）；**变化 > 固定**（改变立场的地方比一直坚持的更有信息量）。
- 运行环境不支持并行 → 六路串行，做一路落盘一路，禁止挂起死等。

**🔴 Phase 1.5 检查点**：六路完成后展示调研摘要表（每路来源数/关键发现/矛盾点/信息不足维度），用户确认再进 Phase 2——垃圾进垃圾出，在这里拦截比在出厂返工便宜。检查点是纠偏不是阻塞：用户不答就按当前质量继续。

### Phase 2 · 三重验证提炼

一个观点收录为心智模型，须过三关（操作细节见 research-protocol.md）：**跨域复现**（≥2 领域）/ **有生成力**（能推断对新问题的立场）/ **有排他性**（不是所有聪明人都这么想）。过 1 关 → 降级为启发式；0 关 → 不纳入。

叠加仓颉三铁律：**信念没有形成故事（「我信 X 是因为经历了 Y」）不准进入；决策案例没有事后反思不准进入；失败不是本人承认的不准进入。**

**直觉条目不适用三重验证**——直觉天生跨不了域（它只在特定情境的线索结构里显形），硬套「跨域复现」会把真直觉全部筛掉。改走「有效性闸」：先判此人直觉所在环境的线索-结果关系是否稳定、反馈是否快而明确，再决定它是「可用直觉」还是「自信」——判定法见「直觉层」。

产出：3-7 个心智模型 + 5-10 条启发式 + 矛盾档案（时间性/领域性/本质性张力三类分别处理，矛盾是特征不是 bug）。**🔴 Phase 2.5 检查点**：展示提炼摘要（模型名清单/启发式条数/DNA 特征/张力对数），用户确认再构建——提炼是主观判断最重的环节，写完几百行才发现方向不对是最大的浪费。

### Phase 3 · 构建

STOP. 读 `references/person-template.md`，按槽位填充，不写自由散文。

REQUIRED 槽位（缺一即半成品）：角色扮演规则（含防漂移）、**回答工作流（问题分类→人物式研究→人物式回答，研究维度从心智模型推导，首步跑「线索扫描」）**、身份卡、心智模型（带证据/应用/局限）、**直觉层（触发线索/秒判/事后归因/失效案例/有效性等级，无锚点不写；素材不足可写留空声明，不算缺槽）**、决策启发式（第一人称习惯式，禁推理步骤）、表达DNA（3 偏好+3 禁忌，调研期量化全表留 research）、时间线、价值观与反模式、内在张力、诚实边界（含调研日期）、三件套（起手式/回答前闸门/失败预防路由含熔断）。

- 长度纪律：正文 <500 行；**中文 token 按字计**（1 汉字≈1-1.5 token），超 5000 就砍。
- 模糊词禁令：「建议/可以考虑/根据情况/灵活把握/视情况而定」出现即返工。
- 在世人物：「最新动态」块必须写成「冻结快照（截至日期）+ 需搜复核」，标注**不得直接当最新引用**。

### Phase 4 · 独立双审计（出厂闸门）

STOP. 读 `references/fidelity-scorecard.md` 后执行。两道审计**各起一个独立子 agent**，生成者不得兼任：

1. **引语/事实审计**：逐条核对每个引号句、年代、人名-事件归属——本流程最容易出的硬伤是**事实倒置与年代错置**。
2. **双盲保真评分**：答题 agent 只读 skill 目录禁联网；评分 agent 独立对照公开立场；3 道已知立场题 + 1 道超范围题 + 1 道风格题 → 产出 `FIDELITY.md`。

**否决项（任一命中即 D 级回炉，不看总分）**：引语审计未跑 / 发现事实倒置 / 在世人物用了无标注的冻结新闻 / 骨架 B 缺出口自检 / 附录 B 伪语录进正文 / **直觉条目无原句锚点（或锚点是「网络流传」）** / **低有效性领域的直觉被写成可复用判断依据** / **事后合理化、情绪、领域外自信冒充直觉进正文**。

### Phase 5 · 棘轮迭代与交付

- **棘轮（达尔文 v2.1 口径）**：一轮只改一个维度（weighted_gap 最大者）；keep/revert **不用绝对分数 delta**（judge 换尺噪音 ±8 会淹没真实增益），用 **paired 同-judge 比较**：同一评委对照 rubric 比改前/改后两版回 {better|worse|tie}，**奇数 ≥3 评委多数决**；绝对分数只用于决定先改谁。
- **validation-gated**：改进必须重过 Phase 4 测试题才 keep；退步用 git revert 干净回滚（不用 reset --hard）。
- **迭代上限**：提炼→审计最多循环 2 轮，或改进幅度连续缩小即停——交付当前最优版本，不无限打磨；剩余薄弱项写进诚实边界。
- 交付三栏：改了什么 / 验证结果（审计与评分实据）/ 未验证项。给第三方的交付物用第二人称写法。

## 骨架 A/B 分流（风险结构）

| | 骨架 A · 不下判断型 | 骨架 B · 下判断型 |
|---|---|---|
| 典型 | 李白、费曼（诗性/好奇驱动） | 杜甫、马斯克、段永平（忧世/改造驱动） |
| 结构 | 松散：视角+表达DNA+诚实边界即可 | 紧凑：必须加**出口自检 + 角色边界 + 熔断条款** |
| 为什么 | 天然不下判断，松散不会出事 | 天然要指认苦难/错误来源，无边界会在现代议题上失控（滑向时政评论/编造数据/只抒情不给方案） |
| 熔断 | 可选 | 必需：启发式含「全押/不可撤回/定死线」类时，先熔断确认再展开 |

套壳复刻旧人物前，先重新评估此人风险结构——1:1 抄骨架是已踩过的坑。

## 直觉层（Intuition Layer）

**直觉不是玄学，是压缩的经验**（Klein 识别启动决策 RPD：专家按模式识别情境，直接生成单一可行方案再心理模拟验收——80–90% 的决策根本没比较过选项）。所以「捕捉直觉」＝捕捉它的**四个副产品**与**三个出口**，不是捕捉那份感觉。

### 能捕捉的 / 捉不到的（写进产物诚实边界）

| 能重建 | 捉不到 |
|---|---|
| **线索**：他一眼看到什么就知道 | 神经元层面的模式匹配过程 |
| **预期**：他预期接下来发生什么（预期落空＝最强信号） | 未说出口的身体感（除非素材里有） |
| **目标**：那一瞬间他在保什么 | 他刻意不公开的判断习惯 |
| **行动脚本**：他的本能第一动作 | 调研截止后的直觉演化 |
| 秒判还是权衡：有没有比较过选项 | |
| 事后归因：他怎么把直觉翻译成理由 | |
| 失效案例：他直觉错在哪（本人承认的） | |

### 捕捉工序：CDM 逆向探询（四轮）

LLM 访谈不到本人，只能对**已发表的叙事性文本**做逆向探询（Critical Decision Method，Klein 1989）。找带「当时我怎么判断」的段落，按四轮问：

1. **选事件**：非例行、多决策点、新手会崩的那一次
2. **拉时间线**：他的认知怎么变——「一开始我以为…直到我看到…」
3. **认知探询**：什么线索让你改判？当时还在保什么别的目标？还有哪些行动可能？**如果那条关键信息没到手，你会怎么做**（假设句是钉住模型形状的钉子）
4. **问新手的错**：他讲「别人都以为 X，其实 Y」的地方——专家看得见、新手看不见的线索全在这里

直觉标记语检索表、四轮问句全文见 research-protocol 第十二节。

### 有效性闸（Kahneman & Klein 2009）：这条直觉能不能当判断依据

直觉可信需两条件同时成立：**环境线索-结果关系稳定** ＋ **充分练习且反馈快而明确**。

- 两条都成立 → 标「可用直觉」，可作判断依据
- 缺一 → 标「这是他的自信／立场，不是可复用直觉」，写明缺哪条，**不得当判断依据**
- **主观确信度不是证据**——原文明言「没有主观标记能区分真直觉与启发式偏见」。他说得再笃定，也不能当可信度依据。

### 反造假三闸（对应铁律三）

1. **锚点制**：每条直觉挂原句，标来源等级——【自述】（本人讲「我当时看到…就知道」）＞【旁证】（他人观察「他没看数据就否了」）＞【追认】（本人事后复盘，含事后合理化风险）
2. **无锚点 → 只进「推测区」**，标「框架推测，非本人自述」，不得混入正文直觉条目
3. **冲突以本人为准**：直觉条目与本人明确说过的分析路径冲突时，删直觉条目，不删他的原话

### 可运行化（这步不做，直觉层就是摆设）

直觉层必须接进「回答工作流」：遇到需要判断的问题，**先用他的线索表扫一遍**——「按他的眼睛，这件事里哪几个信号他会先注意到、哪些他会直接忽略？」再进模型分析。输出才是「像他一样先看出来」，而不是「引用他的观点」。

### 分场景变体

- **无访谈素材（古代人物／已故）**：走「叙事文本逆向重构」——史传里记决断的段落（如「察其色而异之」），标「基于文本叙述重构，非本人自述」，置信度降一级
- **蒸馏用户自己**：可直接跑 CDM 自访，问最近一次「我说不上来但就是不对」的判断——唯一能拿到一手直觉的场合
- **冷门人物**：直觉层整体降级为「推测区」，不硬凑条数

## 更新模式（已有 skill 的增量刷新）

用户说「更新 XX 的 skill」时：读现有 SKILL.md 诚实边界里的调研日期 → 只启动**对话/决策记录/时间线**三路采集 → 对比：新信息强化现有模型→补案例；矛盾→标注变化更新模型；全新思维模式→考虑加模型 → 只更新「最新动态」块与调研时间，**不重写整个 skill**。

## 产物升级模式（工艺流程变了，旧产物怎么回灌）

工序升级后（如 v3 新增直觉层），旧产物不会自动继承。**不要全量重蒸**——旧产物的 `research/` 已落盘，它就是升级的原料。

| 档 | 做什么 | 要新素材？ | 成本 |
|---|---|---|---|
| **L1 结构对齐** | 加新槽位骨架、回答工作流接新步、闸门加条、诚实边界改口径 | 否 | 低，可批量 |
| **L2 内容回灌** | 对已有 `research/` 做新工序的二次挖掘（如 CDM 逆向探询），填真实条目 | 否（用存档） | 中，逐人做 |
| **L3 审计** | 新条目走 Phase 4 对应审计项（如 V6-V8） | 否 | 中 |

五条纪律：

1. **先备份**：`cp -r` 整个产物目录（用户级 skills 无 git）。升级不是重写，必须能回退。
2. **先做一个样板**：工序变更的第一次回灌必然暴露设计缺陷，验收一个再批量。
3. **素材不够就留空声明**，不许为填满槽位编条目（见 REQUIRED 留空豁免）。
4. **先算长度**：正文已 >450 行的，加新槽位前把已有内容**下沉**到 `references/`（下沉不是删），否则撞 500 行纪律。
5. **标注版本谱系**：诚实边界注明「基于 vN 工序构建，vM 回灌 X 层」，让两代产物可区分。

回灌前先做**可行性筛查**（省时）：对 `research/` 全文 grep 新工序的标记语（直觉层用「我一看／直觉／gut feeling／I could tell」）。命中 0 ≠ 一定没有（可能是旁证型，或存档只留了结论），但命中 0 的人物必须回看原始素材确认，不许直接硬编。

## 特殊场景（速查）

- **冷门人物**（可用来源 <10 条）：Phase 0.5 就告知质量受限；心智模型减至 2-3 个并标「基于有限信息推测」；诚实边界加大篇幅。
- **在世的非公众人物**：必须用户提供素材＋提醒征得当事人同意；不做网搜蒸馏（隐私与本人意愿）。
- **蒸馏用户自己**：素材全靠用户提供（文章/录音/决策备忘录）；提醒自我认知偏差——可追问身边人的评价补盲点。
- **蒸馏 ≠ 认同**：提取认知方式不代表赞同其观点（对争议人物尤其要在交付时说清）。

## 诚实边界

- 本 skill 保证**工序**正确，不保证**判断**正确——选哪些心智模型、怎么措辞，仍依赖执行者对人物的理解深度。
- 蒸馏的是**公开信息里的认知框架**；**直觉只到「线索＋秒判＋事后归因」这一层，捉不到那份感觉本身**（见「直觉层」）；捕捉不了调研截止后的突变，公开表达 ≠ 真实想法。
- 评分卡与官方女娲产物同尺（5 维 100 分）以便互测，但分数跨模型/平台不可外推；judge 个体间存在 ±8 噪音，单分不做 keep/revert 依据。
- 素材来源调研时间：2026-10-15。
