# 三个实战案例复盘（2026-10-11）

> 用途：给未来执行「AI 配置升级」的实例提供具体参照——每案包含对象/存储、调研源、关键动作、教训。

## 案例 1：自定义指令（思考规则）→ v3

- **对象与存储**：WorkBuddy「个性化→自定义指令」＝**账号级配置**（本地不可直改）。已排查：settings.json / workbuddy.db / storage / local_storage 均无明文。
- **交付形态**：「可粘贴文本 + 3 步路径」。
- **调研源**：ultrathink-for-all（命令模板原文）、Claude Code effort 机制文档（claude-wiki 镜像）、thinking-modes 与 ultrathink-trigger 技能、dair-ai / anthropics 等仓库地图。
- **迭代过程**：旧五条 → v2（方法论版：思考分级／六步动作／多视角／禁止表演）→ v2.1（+质量优先）→ **v3 融合定稿**（用户指令："这3版结合优化"）。
- **关键动作**：三版融合原则——骨架保旧版、方法论进 v2、价值序进 v2.1；重组为"总则／思考方式／事实与结论／交付纪律"四段十条；消歧（"**明显**简单的问题直接答"）。
- **教训**：写规则文本时，"简单问题直接答"的理由要写成**质量考量**（对简单问题深想无益），而非速度考量——否则与"质量优先"条款打架。定稿前做一次"前后条款打架"检查。

## 案例 2：人设设定 → SOUL.md v3.0

- **对象与存储**：`~/.workbuddy/user-*-personal/SOUL.md`，**本地直改**。注意：根目录下另有一套 SOUL/IDENTITY/USER 是旧模板（英文），真正生效的是 personal 目录这套——改错位置等于白改。
- **调研源**：bchop-studio/soul-templates（8 模板）、will-assistant/openclaw-agents（200+ 人格）、claw-packs（文件职责分离）、dontriskit/awesome-ai-system-prompts（模式分析）、openai-cookbook（personality 指南）、火山方舟角色扮演指南。
- **大佬共识**：五段结构（Core Truths／Boundaries／Vibe／Continuity／**Example Responses**）；30–80 行；**性格在前、职责在后**；示例句校准声音；"两版指令打架，agent 就跟着打架"。
- **关键动作**：补最大缺项——「性格画像」（正面描述：定位／性格／关系）＋「表达风格」（含 5 条示例句）；其余零删除。
- **教训**：① 示例句是双刃剑（会被当"台词"反复用，需标注是"声音样本"）；② 否定式定位（"不是客服"）让气质偏冷，要预留"温度调档"操作项。

## 案例 3：长期记忆 → 记忆体系 v1.1

- **对象与存储**：`MEMORY.md`（本地直改，注入上限 4000 字符）＋ `MEMORY-GUIDE.md`（治理规则）＋ `memory-bank/`（详情层）。
- **调研源**：OpenClaw 实践文档组（best-practices/helpdesk/claw-crew）、dev.to 策展长文、kevin-blog 四层架构、moltbook 记忆卫生、Microsoft Learn「agent memory strategies」。
- **大佬共识**：记忆＝**蒸馏不是存储**；准入三道关（7 天仍重要／不可推导／改变默认行为）；四类持久事实（画像／反馈带 why／项目状态／指针）；MEMORY.md＝"贵地皮"（无情策展）；四级维护节奏；不存密钥、写入标来源。
- **关键动作**：① 购机段下沉（6 bullet → 3 行结论＋指针；**3014 → 2258 字符**）② GUIDE v1.1 补「写入判据／压缩原则／嗅觉测试／权威次序／维护节奏表」③ 索引补 G-006。
- **教训**：做减法要防"用时找不到"——核心层留指针行、详情层同步进索引；下沉后要**主动记住索引 ID**，用户问起能立刻调出。

## 通用模式（三次升级的共同骨架）

1. 先分清**要改的是哪一层**（本地文件 / 云端配置 / 混合）——这决定"直改"还是"给粘贴版"。
2. 调研必须落到**可照抄的共识清单**（来源要去重、要权威），不是泛泛而谈。
3. 改动永远**备份先行 + 零删除**；大条目"下沉"而不是"删除"。
4. 交付物三件套：**可用的新版本体 + 说明文档 + 回退路径**。
5. 收尾两个固定动作：**界面缓存提醒**（关旧开新，勿覆盖）+ **记忆落盘**。
