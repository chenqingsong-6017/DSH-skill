# 路3：孔子的表达 DNA 量化调研

> 本文件只做**语言形式特征**的量化统计，不做思想提炼（那是路1/路2的事）。
> 目标：给 SKILL.md 提供可执行的「表达指纹」——哪些句式、节奏、语气是"孔子腔"。

---

## 0. 数据来源与口径说明

- **底本**：《论语》传世本（二十篇，学界公认稳定文本），并交叉印证 James Legge 理雅各英译本（Project Gutenberg #3330）确认"子曰"章边界与语义。
- **抓取受阻记录**：ctext.org 明确拒绝自动化抓取（反爬提示）；维基文库 zh.wikisource.org 连续 fetch 失败；gushiwen/gushici 站跳转到错误书目。故最终采用**传世经典原文 + 译本交叉验证**，对稳定文本而言可靠度高于被反爬污染的网络文本。
- **信息源黑名单**（本路全程禁用，已规避）：**知乎、微信公众号、百度百科**。伪语录排查亦不引用这三处。
- **统计口径**：
  - 字数 = 汉字数，不含标点。
  - 句 = 以逗号/句号/问号/分号切分的最小语段。
  - 反问句 = 疑问形式承载肯定/否定判断（"乎/哉/焉……也"收尾且无需回答）。
  - 样本：28 段「子曰」章，覆盖二十篇中的学而/为政/里仁/雍也/述而/泰伯/子罕/颜渊/子路/宪问/卫灵公/阳货等篇，兼顾极短句与长句、反问与类比。

## 2. 七轴打标

| 轴 | 定位 | 依据 |
|---|---|---|
| 正式 ↔ **口语** | 偏**口语**（雅言化的口语） | 语录体实录，密集"乎/哉/矣/也/焉/夫"语气词，是说话不是文章；但经过凝练，是"凝练的口语"而非市井白话 |
| 抽象 ↔ **具体** | 偏**具体** | 论"仁""德"皆落于自然/器物意象：北辰、流水、松柏、輗軏、浮云、山水、松柏 |
| 谨慎 ↔ **断言** | 偏**断言**，但有边界 | "必""必也""可以"高频（全书"必"约 76 次）；但保留"吾未见""不知""焉知"式留白，不把话说死 |
| 学术 ↔ **通俗** | 偏**通俗** | 不造术语、不下定义，用日常物象讲抽象道理，一听就懂 |
| 长句 ↔ **短句** | **极短句** | 平均 4.7 字/句，几乎无嵌套从句 |
| 铺垫 ↔ **结论先行** | 偏**结论先行** | 先抛判断再补理由（"德不孤"→"必有邻"；"君子喻于义"→"小人喻于利"），少铺垫 |
| 数据 ↔ **叙事** | 偏**叙事/具象** | 不靠数字论证，靠场景与意象；偶用数字排比（三十而立、四十不惑、三人行）作节奏，而非量化 |

## 3. 高频词与惯用句式

### 3.1 高频词（全书）

| 词 | 频次（约） | 角色 |
|---|---|---|
| 君子 | 107 | 核心对举词，与"小人"成对 |
| 仁 | 109 | 核心概念，但多用行为描述而非定义 |
| 道 | 89 | 核心名词 |
| 必 | 76 | 断言标记，语气指纹 |
| 吾 | 100+ | 第一人称主格（"我"约 40+，多用于对比/强调，如"我未见好德如好色者"） |
| 不 | 极高频 | 否定式说理，以"不是什么"逼近"是什么" |
| 小人 | 24 | 与"君子"对举 |
| 知 | 高频 | 兼"知道"与"智慧" |

### 3.2 惯用句式（全书归纳，含出处）

| 句式 | 功能 | 例句 |
|---|---|---|
| **不亦……乎** | 反问表肯定，定调式收尾 | 学而时习之，不亦说乎？（学而·1） |
| **……，斯……矣 / 也已** | 条件推论 | 攻乎异端，斯害也已（为政·16） |
| **其……乎 / 其……哉** | 推测反问 | 大车无輗，小车无軏，其何以行之哉？（为政·19） |
| **焉知 / 焉能 / 焉得** | 反问否定 | 后生可畏，焉知来者之不如今也？（子罕·22）；未能事人，焉能事鬼？（先进·11） |
| **君子……，小人……** | 对偶对比 | 君子喻于义，小人喻于利（里仁·16）；君子坦荡荡，小人长戚戚（述而·36） |
| **……不如……** | 层递比较 | 知之者不如好之者，好之者不如乐之者（雍也·18） |
| **譬如……** | 比喻引入 | 为政以德，譬如北辰（为政·1） |
| **必有 / 必也** | 强断言 | 德不孤，必有邻（里仁·25）；三人行，必有我师焉（述而·21） |
| **何……之有** | 反问 | 何有于我哉？（述而·2） |
| **……者，……也** | 判断句 | 性相近也，习相远也（阳货·6）的"也"尾判断变体 |

## 4. 收敛：3 条最指纹的偏好 + 3 条禁忌（候选）

> 供主 agent 写入 SKILL.md，此处给「候选 + 依据」，最终取舍由主 agent 定。

### 4.1 三条偏好候选

1. **短句断论，一句一义，结论先行**
   平均 4.7 字/句，一章一个判断；先抛结论再补理由。写孔子腔，先给论断，不绕弯。
   - 例证：德不孤，必有邻（里仁·25）；有教无类（卫灵公·39）。

2. **对偶排比立骨架，正反对比成节奏**
   57% 的章含对偶/排比，且多"君子/小人""知者/仁者""其身正/不正"式二元对举。
   - 例证：君子喻于义，小人喻于利（里仁·16）；知者乐水，仁者乐山（雍也·21）。

3. **反问定调 + 借物象说理**
   用"不亦……乎""焉知……""其……哉"式反问表肯定/否定；用北辰、流水、松柏、浮云等自然器物意象承载抽象概念，不下定义。
   - 例证：人不知而不愠，不亦君子乎？（学而·1）；逝者如斯夫，不舍昼夜（子罕·16）。

### 4.2 三条禁忌候选

1. **忌抽象玄谈、术语堆砌**
   孔子讲"仁""道"从不说"仁者，抽象之谓也"，而落于"己所不欲，勿施于人"的行为描述。写孔子腔，禁止用学术黑话和空洞定义。

2. **忌长句嵌套、层层从句**
   平均句长不足 5 字，没有现代学术腔的冗长从句。禁止用"在……的前提下，通过……从而实现……"式句式。

3. **忌绝对化断言到底、不留余地**
   孔子断言多用"必"，但也常说"吾未见""不知""焉知"，有认知谦逊。禁止把话说死、把判断推向绝对；保留"未知生，焉知死"式的留白。

## 5. 伪语录 / 断章排查（供附录 B 黑名单）

### 5.1 断章取义（原句存在，但流传中被截断/曲解）

| 流传说法 | 真相 | 出处 |
|---|---|---|
| 「以德报怨」 | **被断章**。孔子明确反对以德报怨。原文：或曰"以德报怨，何如？"子曰"何以报德？以直报怨，以德报德。"主张"以直报怨" | 宪问·36 |
| 「唯女子与小人难养也」 | **被截半句**。全句"唯女子与小人难养也，近之则不孙，远之则怨"，讲人际亲疏距离之难，非孤立攻击女性 | 阳货·25 |
| 「父母在，不远游」 | **被截后半句**。"游必有方"被删，原意是"出游须有方向/告知去处"，非禁止远游 | 里仁·19 |
| 「民可使由之，不可使知之」 | **句读之争**。断为"民可，使由之；不可，使知之"等异读，脱离句读歧义不宜作"愚民"定论 | 泰伯·9 |
| 「既来之，则安之」 | 原义"使远人来归则使其安顿"（治国语境），非今义"既然来了就安心待着" | 季氏 |
| 「学而优则仕」 | **非孔子语**，是**子夏**说的（"仕而优则学，学而优则仕"），常被误归孔子 | 子张·19 |
| 「食色性也」 | **非孔子语**，是**告子**说的 | 孟子·告子上 |
| 「温良恭俭让」 | 是**子贡形容孔子**的话（"夫子温良恭俭让以得之"），非孔子原话 | 学而·10 |

### 5.3 现代伪托鸡汤（《论语》查无）

- 「未经他人苦，莫劝他人善」——现代网络伪托，查无。
- 「以德报怨，何以报德」——"何以报德"虽为原文，但整句是后世拼贴，且把孔子反对的"以德报怨"当孔子主张传播。
- 「半部论语治天下」——赵普典故，非《论语》原文，亦非孔子语。
- 「君子报仇，十年不晚」——俗语伪托，查无。
- 「万般皆下品，惟有读书高」——宋人《神童诗》，非孔子。
- 「宁可我负天下人」——小说/戏曲曹操语，与孔子无关（防混淆用）。

## 6. 一句话结论（回传主 agent）

孔子的表达 DNA = **短句断论（≈5 字/句）+ 对偶排比（57%）+ 反问定调（不亦/焉知/其……哉）+ 借物象说理（北辰/流水/松柏/浮云）**，先结论后理由，断言有力但留认知余地；严禁抽象术语、长句嵌套、绝对化断言。伪语录重点排雷：「以德报怨」是断章（原为"以直报怨"）、「学而优则仕」「食色性也」非孔子语、老孟庄周易大学中庸的大量名句被张冠李戴。
