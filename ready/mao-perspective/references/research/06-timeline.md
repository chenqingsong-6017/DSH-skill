# 06 · 人物时间线

> 调研维度：毛泽东生平关键节点、思想转折点
> 可信度标注：【二手】权威史料

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1893 | 生于湖南湘潭韶山冲农家 | 出身底层，深知农民与乡土中国 |
| 1913–1918 | 湖南第一师范（老师杨昌济） | 打下古典功底，接受经世致用学风 |
| 1918–1919 | 赴北京，在北大图书馆工作 | 接触马克思主义与《新青年》 |
| 1920–1921 | 确立马克思主义信仰，出席中共一大 | 从改良转向革命 |
| 1925 | 《中国社会各阶级的分析》 | 形成「谁是敌人谁是朋友」的阶级分析 |
| 1927 | 秋收起义，上井冈山 | 走出「农村包围城市」的独特道路 |
| 1930 | 《反对本本主义》《星星之火，可以燎原》 | 「没有调查没有发言权」；革命必胜的战略定力 |
| 1934–1935 | 长征；遵义会议确立领导地位 | 独立自主、灵活机动 |
| 1937 | 《实践论》《矛盾论》 | 方法论成型：认识论 + 辩证法 |
| 1938 | 《论持久战》 | 战略分析典范 |
| 1942 | 延安整风 | 确立「实事求是」为思想路线 |
| 1945 | 中共七大，毛泽东思想确立 | 思想体系成为指导思想 |
| 1949 | 新中国成立 | 从革命转向建设 |
| 1950 | 抗美援朝 | 「打得一拳开，免得百拳来」 |
| 1956 | 《论十大关系》 | 探索中国自己的建设道路 |
| 1957 | 《关于正确处理人民内部矛盾的问题》 | 矛盾论在社会主义建设时期的运用 |
| 1966–1976 | 文化大革命 | 晚年偏离实事求是，官方决议已作评价 |
| 1976 | 逝世 | —— |

## 思想转折点（重点标注）

- **1937**：哲学两论（《实践论》《矛盾论》）——从「会打仗」升维到「有方法」。
- **1942**：延安整风——「实事求是」从个人习惯变为全党的思想路线。
- **1956–1957**：从革命思维转向建设思维，开始探索「中国自己的路」。
- **1966 以后**：晚年偏离——这条转折是理解「方法论与执行之间裂缝」的关键。
