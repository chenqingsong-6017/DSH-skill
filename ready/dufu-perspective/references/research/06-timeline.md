# 06 · 人物时间线

> 调研维度：杜甫（712–770）生平关键节点
> 可信度标注：综合史传（新旧《唐书》杜甫传）与杜甫自述诗互证

## 一、完整时间线

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 712（先天元年/太极元年） | 生于河南巩县（今巩义），出身「奉儒守官」的京兆杜氏，祖父杜审言为名诗人 | 儒者家世 + 诗歌家学，奠定「致君尧舜」与「诗是家业」的双重底色 |
| 约719 | 七岁能诗（「七龄思即壮，开口咏凤凰」）；少年游洛阳，受公孙大娘、李龟年、吴道子等艺术熏染 | 早慧 + 盛唐文化的全面滋养，形成开阔的美学视野 |
| 731–734 | 漫游吴越 | 「裘马清狂」的少年快意 |
| 735（一说 736） | 应进士试落第（地点有洛阳／京兆二说，学界未定） | 首次受挫，但仍「裘马清狂」，抱负未减 |
| 736–740 | 漫游齐赵（「放荡齐赵间，裘马颇清狂」），作《望岳》「会当凌绝顶，一览众山小」 | 青年昂扬，心怀天下 |
| 744（天宝三载） | 洛阳遇李白，同游梁宋（会高适） | 与李白的知音之交，此后终身怀念 |
| 745（天宝四载） | 齐鲁再会李白，此后再未相见 | 「醉眠秋共被」的情谊成为终身精神寄托 |
| 746–755 | 困居长安十年，科举落第、献赋干谒皆无果 | 目睹统治集团腐败，从「个人失意」转向「忧国忧民」 |
| 755 | 任右卫率府兵曹参军（为生计而受小官）；安史之乱爆发；幼子饿死，作《自京赴奉先县咏怀五百字》「朱门酒肉臭，路有冻死骨」 | 个人苦难与时代苦难合流，「诗史」意识成型 |
| 756 | 投奔灵武肃宗途中被俘，困于长安，作《春望》《月夜》 | 国破家亡之痛的巅峰 |
| 757 | 逃出长安投凤翔肃宗，授左拾遗；因房琯事上疏触怒肃宗，险遭刑责 | 仕途顶点亦为转折点，「言虽狂，不失谏臣体」 |
| 758 | 贬华州司功参军 | 被疏远，政治理想受挫 |
| 759 | 弃官，流亡秦州、同谷，入蜀；作「三吏三别」 | 思想变化最大、创作丰收的一年 |
| 760 | 成都，浣花溪草堂建成（三月堂成） | 暂得栖身，写下大量怡情小诗 |
| 761 | 八月，草堂为秋风所破，作《茅屋为秋风所破歌》 | 由己之寒推及天下寒士 |
| 762 | 避徐知道之乱，流寓梓州（今三台） | 再度流离，草堂不得归 |
| 763 | 在梓州闻官军收复河南河北，作《闻官军收河南河北》（浦起龙称「生平第一首快诗」） | 家国悲欢的极致 |
| 764 | 严武荐为节度参谋、检校工部员外郎（「杜工部」之由来） | 短暂入幕，不久辞归 |
| 765 | 严武病逝；五月离成都东下，经嘉戎渝忠，秋抵云安（今重庆云阳），因病滞留 | 失去依靠，开始晚年漂泊 |
| 766 | 春移居夔州白帝城（今奉节），得夔州都督接济 | 暂得栖身，迎来创作爆发 |
| 766–768 | 居夔州近两年，作《秋兴八首》（766 秋）、《登高》（767 秋，胡应麟推为「古今七言律第一」） | 晚年艺术巅峰，沉郁顿挫至极 |
| 768 | 出峡，辗转江陵、岳阳 | 漂泊无定 |
| 770（大历五年） | 病逝于湘江舟中（长沙往岳阳途中），终年 59 岁；绝笔《风疾舟中伏枕书怀》「战血流依旧，军声动至今」 | 至死以国难为念，完成「诗圣」人格的最后注脚 |

## 二、生平分期的思想演变

1. **读书游历期（712–745）**：昂扬、自信、心怀天下（《望岳》）。
2. **困守长安期（746–755）**：由个人失意转向忧国忧民，思想深刻化（《兵车行》《丽人行》）。
3. **战乱流离期（756–759）**：国破家亡之痛，「诗史」成就最高峰（《三吏三别》《北征》）。
4. **漂泊西南期（760–770）**：沉郁顿挫的艺术巅峰，晚年仍心系苍生（《秋兴八首》《登高》）。

## 三、备注（学术存疑点）

- 出生地：巩县（今河南巩义）为主流说法，亦有祖籍襄阳之说。【二手】
- 卒地：一说「舟中」、一说「耒阳」，主流为湘江舟中。【二手】
- 官职：任「右卫率府兵曹参军」一说「胄曹参军」，存在争议。【二手】
- 应进士试年份：735（仇兆鳌《杜工部年谱》据「忤下考功第」推定）一说 736（洪业、邝健行考定）；地点亦有洛阳／京兆二说。【二手】
- 《茅屋为秋风所破歌》系年：上元二年（761）八月，非草堂初建的 760 年。【二手，仇兆鳌系年】
- 绝笔：《风疾舟中伏枕书怀》一般认为是绝笔，但非定论。【二手】
- 「集大成」之论：元稹《墓系铭》开先声，「集大成」三字首发于苏轼，不可系于元稹。【二手】
