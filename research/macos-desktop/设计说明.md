## 二、设计思路（提炼自 Apple 官方 HIG，非凭感觉）

素材全部来自一手信源：Apple 官方 HIG（材质/颜色/字体/动效/布局五篇）+ 官方 Liquid Glass 采纳文档 + macOS 27「Golden Gate」公开资料（2026-06 WWDC26）。提炼出 5 个心智模型，直接指导实现：

1. **内容优先，控件退后**——玻璃材质只出现在"功能层"（菜单栏/Dock/面板），窗口正文永远不透明；
2. **材质即层级**——浮起感 = 半透明底 + 背景模糊 + 顶部高光 + 多层阴影，不用边框画框；
3. **同心与统一**——全站一套圆角阶梯（窗口 11px / 面板 8px / 控件 7px / 图标 22.4% 圆方）；
4. **克制动效**——悬停 140ms / 浮层 220ms / 窗口 320ms，统一两条缓动曲线，支持"减弱动态效果"；
5. **可读性优先**——这是 macOS 26 挨批、27 修正的核心教训：复杂背景上的玻璃面板必须先过对比检查。

## 三、关键实现要点

1. **设计令牌全程变量化**：约 60 个 CSS 变量覆盖配色/材质/阴影/圆角/动效，深浅两套随 `data-theme` 切换——深色不是反相，是重新配的对比关系。
2. **玻璃三件套**：`backdrop-filter: blur(30–44px) saturate(180–200%)` + 半透明底 + `.5px` 描边/顶部 inset 高光。菜单栏、下拉菜单、控制中心、通知、Dock 全部按此配方，档位分级统一。
3. **Dock 高斯放大**：`scale = 1 + 0.55·e^(−(d/σ)²)`，σ=1.35×图标尺寸；图标加大时左右 `padding` 同步补偿，避免互相叠压；`transform-origin: bottom` 保证"从底部长高"。
4. **窗口管理器**：Pointer Events + 指针捕获实现拖拽/右下角缩放；最小化用"动态变换原点指向 Dock 图标 + 缩放到 6%"，视觉上等同于被吸进 Dock；交通灯 12px，符号仅悬停显示，未聚焦窗口三点全灰。
5. **完整可玩的应用**：访达（文件系统导航 + 预览窗口）、备忘录（可编辑 + 自动保存 localStorage）、计算器（完整运算 + 键盘输入）、终端（help/ls/neofetch/open 等 10 条命令 + 历史）、系统设置（外观/墙纸/程序坞实时调参）、照片（灯箱）、Safari（起始页）。
6. **细节**：菜单悬停切换、⌘/Ctrl+空格 聚焦搜索、右键菜单、控制中心亮度滑块真的调暗屏幕、通知中心横幅、睡眠/关机遮罩、URL 参数（`?theme=dark&wp=2&apps=finder,notes&spot=1`）做状态注入。
7. **对抗性自查修过的坑**：`hidden` 属性被 `display:flex` 覆盖（遮罩常驻）→ 全局补规则；`contenteditable` 用 `innerText` 保换行；窗口恢复时开启动画重播 → `.opened{animation:none}`；无头浏览器四场景截图验收（浅色/深色/聚焦/应用特写）。

## 四、你可以先试这些

- 鼠标扫过 Dock（放大效果）、点图标开应用、拖标题栏、双击标题栏缩放、绿点缩放、黄点最小化（看它"吸"进 Dock）
- Control + 空格 → 输入「访」回车；右上角控制中心 → 拖亮度滑块；开关 Wi-Fi 看菜单栏图标变化
- 系统设置 → 外观：切深色/自动、换强调色；墙纸：四套渐变；程序坞：调大小和放大开关
- 桌面右键 → 新建文件夹 / 换墙纸；终端里输 `neofetch` 和 `sudo`

## 五、诚实边界

- **字体**：SF Pro 不能分发，用系统字体栈 + Inter 近似（Mac 上自动落到真 SF）；**图标**：全部手绘 SVG 近似，非 Apple 官方素材，商用需自行解决授权。
- **数值**：blur 半径、透明度等 Apple 未公开 px 级规格，本项目数值是"对齐观感的工程近似"。
- **环境**：Chromium/Edge 实测通过；Firefox 的 `backdrop-filter` 支持较弱（会出现无模糊降级）；同屏玻璃层多时低端机可能掉帧。
- **时效**：设计基线为 macOS 27 Golden Gate（2026 秋），超 6 个月建议复查 Apple 官方页面。
